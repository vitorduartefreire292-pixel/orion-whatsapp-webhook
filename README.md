# Orion WhatsApp Webhook

Servidor para receber mensagens do WhatsApp via Meta Cloud API e responder usando IA.

## Environment Variables no Render

- VERIFY_TOKEN
- META_ACCESS_TOKEN
- PHONE_NUMBER_ID
- META_GRAPH_VERSION
- OPENAI_API_KEY
- OPENAI_MODEL

Depois do deploy, o webhook será:
https://SEU-ENDERECO.onrender.com/webhook

Não coloque tokens ou chaves no GitHub; use Environment Variables do Render.
